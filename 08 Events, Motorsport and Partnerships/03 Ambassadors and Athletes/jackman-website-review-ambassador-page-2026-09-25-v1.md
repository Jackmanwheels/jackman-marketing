# Website Review — Ambassador Page vs. Campaign Brief

**Page reviewed:** `jackmanwheels.com/pages/ambassadors` (live)
**Compared against:** `jackman-campaign-brief-ambassador-program-launch-2026-09-23-v1.md`
**Date:** 2026-09-25
**Status:** Review — no page changes made (draft-to-file only)

---

## What's there

- Hero: "Ambassador Program" + a heritage blurb — no founding decade, no founder names,
  both correctly cautious per the still-unratified guardrails.
- "What You Get": ambassador discount, welcome kit, community access, brand features.
- "What We Look For": active builder/enthusiast, truck/Jeep/off-road community,
  authentic social presence, represents the brand well.
- Application form: first/last name, email, phone, Instagram handle, other socials,
  approximate following, vehicle (year/make/model), and a free-text "why" field.
- "What we've been up to" — three live blog posts feeding the page real content.
- Title tag: "Jackman Wheels Ambassador Program | Apply Now" — solid, on-target.

## What's missing, against the brief

1. **No tiers.** This is the brief's central structural idea — Crew / Builder /
   Flagship, each with different asks and benefits — and the live page treats every
   applicant the same: one discount, one set of expectations, one form. Worth confirming
   whether tiers were dropped intentionally or just haven't been built yet.
2. **No platform-segment framing.** The brief proposed showing the eight platform
   segments (Sierra/Silverado, Tacoma, 4Runner, Gladiator/JK–JL, Bronco, F-150/Super
   Duty, Ram, Overland) as their own section, tied to "one hero vehicle per segment."
   Not present — the vehicle field captures year/make/model as free text, which is
   enough data to sort into segments after the fact, but there's no up-front framing
   that this is how the program is organized.
3. **No Off-Road Expo tie-in.** Nothing on the page references the show (Oct 3–4, eight
   days out) or that Jackman is scouting there. Given the brief's whole sequencing was
   built around the expo as the scouting/urgency moment, this feels like the biggest
   missed opportunity if the page is meant to be live before the show.
4. **No city field.** The brief wanted one, for event/regional targeting. Minor — the
   form is otherwise a slightly richer superset of what the brief asked for (it also
   captures phone, which the brief didn't call for).
5. **Can't confirm from the front end where submissions actually go.** The form returns
   a generic "thanks for getting in touch" — the brief called for a dedicated Klaviyo
   "Ambassador Applicants" list. Worth confirming this is actually wired up rather than
   just landing in a generic contact-form inbox.

## Resolved 2026-09-25 — open call now, tiers later

Austin's call: run the page as the open call it already is; tiers (Crew/Builder/
Flagship) and the platform-segment framing are a **Phase 2**, to be built once the
program has an initial wave of applicants to sort into them — not before. So the "no
tiers" gap noted below was never a defect in the live page; it's just not built yet by
design. The Off-Road Expo tie-in (drafted below) is the only change needed on the page
right now.

**Not yet decided, worth a task when it's time:** how the Flagship pilots (one hero per
platform segment) get recruited once tiers exist — direct outreach from the prospect
sheet versus sorting them out of the open-call applicant pool. Revisit after the expo,
once there's real application data to look at.

## Recommendation

Before the expo (8 days out): add the Off-Road Expo copy below. Confirm the Klaviyo
wiring separately — still unconfirmed, not blocking the copy addition. Tiers and the
segment grid are Phase 2, per the resolution above — nothing else needed on this page
before the show.

## Addition drafted — Off-Road Expo tie-in

Two pieces, for two placements. Neither requires a new page section from scratch if the
theme already has a banner/callout component used elsewhere on the site — reuse that
pattern rather than building a new one.

### 1. Callout banner, directly below the hero (before "What You Get")

Highest visibility — every visitor sees this before anything else.

> **WE'RE AT OFF-ROAD EXPO — OCT 3–4, COSTA MESA**
> Scouting our first ambassador class in person. Find the Jackman booth, or apply below.

Build note: single-line banner, same treatment as any existing announcement-bar or
callout component on the site. If none exists, a simple bordered text block above the
"What You Get" heading works.

### 2. Short reinforcement line, directly above the Application form

Catches anyone who scrolled straight to the form without reading the top of the page.

> Heading to Off-Road Expo, Oct 3–4 in Costa Mesa? Stop by the Jackman booth — or apply
> right here.

Build note: one line, placed between the "Ambassador Application" heading/subhead and
the form fields. Doesn't need its own section.

**Facts used, both confirmed:** Oct 3–4, 2026, OC Fair & Event Center, Costa Mesa — per
`03 Content and Social/jackman-social-playbook-2026-09-14-v1.md`. No founder names, no
spec/certification claims, no militarized language. Both lines checked against
`jackman-brand-guidelines` and passed through `humanizer` — kept short and direct rather
than "announcement" voice, consistent with the rest of the page's tone.
