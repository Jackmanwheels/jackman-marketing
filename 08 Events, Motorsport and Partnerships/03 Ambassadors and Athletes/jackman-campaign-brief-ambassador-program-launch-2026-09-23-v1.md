# Ambassador Program Launch — Campaign Brief

**Objective:** Launch a tiered Jackman Wheels ambassador program, piloted with one hero
vehicle per platform segment, using Off-Road Expo (Oct 3–4) as the in-person scouting
moment that feeds the post-show launch.
**Audience:** Overland/off-road micro-creators and builders (existing sourcing: 5-25K
follower range) plus a small number of flagship per-segment hero vehicles as pilots.
**Target date:** Scouting at Off-Road Expo, Oct 3–4, 2026 (OC Fair & Event Center, Costa
Mesa). Program landing page + application flow live by **Oct 13, 2026** (one week after
the show, to convert expo contacts while they're still warm).
**Status:** Draft
**Version:** v1

---

## The idea, as given

Austin wants to launch the ambassador program: recruit one strong hero vehicle per
manufacturer segment as initial pilots ("test dummies" to learn what the program
actually needs before scaling), build toward a tiered structure, and use the upcoming
Off-Road Expo to scout candidates in the parking lot in person. Needs a landing page,
email marketing, and social content.

**Assumptions made below, flagged because they weren't specified:**
- **Segment list** — reused the 8 vehicle-platform Story Highlight containers already
  set up per the social playbook, rather than inventing a new list: Sierra/Silverado ·
  Tacoma · 4Runner · Gladiator/JK–JL · Bronco · F-150/Super Duty · Ram · Overland.
- **Tier structure** — proposed below (Crew / Builder / Flagship). Not previously defined
  anywhere in the department's files; this is new work, not a house standard being
  applied.
- **Sequencing** — 10 days isn't enough to build and launch a full tiered program with a
  polished landing page before the show. Recommendation: treat Off-Road Expo as the
  scouting/capture event (this is already close to what the social playbook's Week 2/
  show-day plan does — collecting handles and permission on the spot — this brief
  formalizes it into an actual application ask), and launch the full program the
  following week using expo contacts as the first wave.
- **Budget is not addressed here.** Per `D-09` in the decisions inbox: nothing is
  approved because it's in a document. Product seeding, stipends, or any paid tier
  benefit needs Austin's explicit sign-off separately before it's offered to anyone.

against existing URL patterns before building). Sections, top to bottom:
1. Hero — one strong lifestyle image, headline stating what the program is and who it's

## Why it's built this way

**One per segment, not a broad open call, first.** Austin's own framing — "test dummies"
— is the right instinct: eight relationships are manageable to actually run well; a
broad open call before the program's mechanics are proven would create obligations
nobody's staffed to fulfill. The tiers exist so the Flagship pilots aren't the *entire*
program — Crew and Builder give the existing prospect list (already sourced, already
5-25K-follower-range) somewhere to land without needing a hero-level commitment.

**Off-Road Expo as capture, not launch.** Ten days doesn't allow for a landing page,
application flow, and Klaviyo integration to go live responsibly before the show. But
the show is also the best possible scouting environment — attendees are already
self-selected as exactly the audience this program wants. Splitting scouting (at the
show) from launch (the following week) gets the best of both without rushing a page that
represents an ongoing relationship, not a one-off sale.

**Ties into existing work rather than duplicating it.** The platform segments reuse the
Story Highlight structure already built. The scouting tactic formalizes what the social
playbook already planned to do at the booth. The first content output (*How It's Built*)
is the series already slated to launch first, for the same reasons (cheap, Collab-native,
not gated on Sand Hollow). This program gives existing plans their first real subject
rather than starting a parallel initiative.
