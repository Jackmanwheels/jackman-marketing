# Marketing Crew — Agents

This folder holds the Jackman marketing AI agents. They're built one at a time, not all
at once.

## Structure

One subfolder per agent:

```
agents/
  executive-assistant/   ← lead agent, built first
  <next-agent>/          ← added when we get to it
```

## The Executive Assistant is the lead

The Executive Assistant (EA) is the first agent and sits at the top of the crew. Every
other agent gets added underneath it later, one at a time, as Austin decides to build
them — there's no fixed roadmap for which comes next.
